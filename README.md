# Conduit Container

Description:
In this project, you’ll learn how to containerize a full-stack web application consisting of a Django backend and a corresponding Angular client. The container setup can be executed using `compose.yaml` to simplify container management.

Project Purpose
In this project, users will learn how to containerize legacy projects to keep them running.

The application should be containerized and fully executable with compose -> the application can be started with a simple `docker compose up -d`.

This task demonstrates the challenges a DevSecOps engineer might face in their daily work.
